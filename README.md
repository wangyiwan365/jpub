# Java Application Packager

A self-contained Java application packaging tool that bundles a JVM runtime and generates a native launcher(.exe), allowing users to run Java applications without installing Java.








-------------------------------------------------------------


# Java 应用打包工具

一个独立的 Java 应用打包工具，捆绑了 JVM 运行环境并生成本地启动器（.exe），让用户无需安装 Java 就能运行 Java 应用。
